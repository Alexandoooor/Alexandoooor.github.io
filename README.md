# Alexandoooor.github.io

Personal portfolio and blog, built with [Astro](https://astro.build) and deployed to GitHub Pages via GitHub Actions.

## Development

```sh
npm install
npm run dev      # local dev server
npm run build    # static build to ./dist
npm run preview  # serve the built site
```

Posts live in `src/content/posts/`, projects in `src/data/projects.json`.
